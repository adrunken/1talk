# Font Awesome Fonts

This directory should contain Font Awesome font files.

## Required Files

The following Font Awesome 6.6.0 fonts are required:

### Woff2 Fonts (Recommended for modern browsers)
- fa-brands-400.woff2
- fa-regular-400.woff2
- fa-solid-900.woff2
- fa-v4compatibility.woff2

### TrueType Fallback Fonts (For older browsers)
- fa-brands-400.ttf
- fa-regular-400.ttf
- fa-solid-900.ttf
- fa-v4compatibility.ttf

## How to Download

These fonts are available from Font Awesome CDN or from the user's asset links:
- fa-brands-400.woff2: https://cdn.builder.io/o/assets%2Fda25f5770890491c94a926e504cfe446%2Fee7f78d38e5a485c89c42fce5566693d
- fa-regular-400.woff2: https://cdn.builder.io/o/assets%2Fda25f5770890491c94a926e504cfe446%2F087241b18c6e4352833ca9b2ec08879f
- fa-solid-900.woff2: https://cdn.builder.io/o/assets%2Fda25f5770890491c94a926e504cfe446%2Fb2c87a6e8c50413d8161ca6785bff9fe
- And so on for the TTF files...

Alternatively, download from: https://fontawesome.com/download

## Font Loading

The CSS file at `css/all.min.css` references these fonts. If fonts are not available, the browser will use fallback fonts and the game will still be fully functional.
